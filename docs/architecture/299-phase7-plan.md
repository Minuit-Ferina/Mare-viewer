# Phase 7 Plan

Date: 2026-05-23

Branch: `phase7`

Base branch: `phase6`

## Purpose

Phase 7 starts after the completed phase 6 checkpoint.

The goal is to finish the remaining small `lltoolmorph` appearance preview
boundaries before moving to a new renderer owner.

This phase stays narrow:

- no source moves;
- no runtime behavior changes;
- no broad `llui` or `pipeline` work;
- no Vulkan, Metal, SDL, app lifecycle, multi-window, or multi-login work.

## Baseline From Phase 6

Phase 6 ended with:

- `LLVisualParamHint` and `LLVisualParamReset` mapped;
- `LLVisualParamHint::needsRender()` split into predicate helpers;
- `LLVisualParamHint::preRender(...)` split into preview state helpers;
- `LLVisualParamHint::render()` split into camera, background, impostor,
  restore, and finalization helpers;
- OpenGL containment guardrails passing;
- targeted `lltoolmorph.cpp.o` builds passing;
- final non-clean `mare-viewer` integration checkpoint passing with
  `[100%] Built target mare-viewer`.

Phase 7 must preserve this baseline.

## Phase 7 Direction

Primary direction:

- keep working inside `indra/newview/lltoolmorph.*`;
- finish the small UI-facing draw/reset functions left after phase 6;
- make ownership names explicit before leaving this owner.

First candidate:

- `LLVisualParamHint::draw(F32 alpha)`

Reason:

- it is the UI-facing draw path for the dynamic texture generated by
  `LLVisualParamHint::render()`;
- it directly touches `gGL`, texture unit binding, `LLGLSUIDefault`, and the
  hint quad;
- it is smaller and lower risk than moving to a new dynamic texture owner.

Second candidate:

- `LLVisualParamReset::render()`

Reason:

- it is already mapped as part of the same owner file;
- it resets avatar appearance state after hint rendering;
- it is very small but still owns important dynamic texture ordering semantics.

## Allowed Work

Allowed phase 7 work:

- architecture notes under `docs/architecture/`;
- updates to `todo.md` and `AGENTS.md`;
- owner-local helper extraction in `indra/newview/lltoolmorph.*` after a
  task-specific map exists;
- targeted `lltoolmorph.cpp.o` builds;
- non-clean integration build only after a meaningful source checkpoint.

## Not Allowed

Do not do these in phase 7:

- touch `pipeline.cpp`;
- begin broad `llui` cleanup;
- move files;
- change visual param values;
- change dynamic texture order buckets;
- change avatar reset timing;
- change texture binding semantics;
- change hint quad geometry or coordinates;
- start app lifecycle, SDL, Vulkan, Metal, multi-window, or multi-login work.
